# Release note — the type surface of `@inflexa-ai/harness`

This text ships in the pull-request description and in the body of the next
GitHub Release of `@inflexa-ai/harness`. It is written in Simplified Technical
English, as the repository rules ask for GitHub text.

---

## BREAKING: each `interface` is now a `type`

This release ships each object type of `@inflexa-ai/harness` as a `type` alias.
Before this release, each of them shipped as a TypeScript `interface`. The
names, the members, and the generics do not change.

A `type` does not permit a declaration merge. Code of this form does not
compile. TypeScript reports error TS2300 (duplicate identifier):

```ts
declare module "@inflexa-ai/harness" {
    interface ConversationAgentDeps {
        myExtraField: string;
    }
}
```

Do this instead. Define a local intersection type at your boundary, and give its
values where the harness type is expected. Structural typing accepts them:

```ts
import type { ConversationAgentDeps } from "@inflexa-ai/harness";

type MyAgentDeps = ConversationAgentDeps & { myExtraField: string };
```

immediately before the change: 825 declarations across 277 modules. Each row

A merge into a module-internal declaration was also possible before this
